# Agent Letterbox for Herdr roadmap

## v0.1 scope (local)

- Durable letters + reply-first protocol
- `letterbox herdr setup|run|register|unregister|status`
- Registry-first `adapters/herdr.sh` using `pane send-text` + `pane send-keys enter`
- Local Herdr only

## Not supported

- SSH/remote Herdr session packaging
- Plugins marketplace distribution as a dependency
- cmux/tmux/desktop/webhook adapters in this tree
